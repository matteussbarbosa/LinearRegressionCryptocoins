# Cryptocurrency Linear Regression Analysis

## Overview

This project explores the application of **linear regression** to cryptocurrency market data using Python.

The project was developed to study relationships between cryptocurrency variables and apply a fundamental statistical modeling technique commonly used in data analysis and machine learning.

## Objectives

* Load and process cryptocurrency market data.
* Explore relationships between variables.
* Apply a linear regression model.
* Analyze the fitted relationship and model behavior.
* Visualize the results.

## Technologies

* Python
* Linear Regression
* Statistical Analysis
* Data Analysis
* Matplotlib

## Methodology

The analysis follows a basic data modeling workflow:

1. Data preparation
2. Exploratory analysis
3. Definition of the variables used in the regression
4. Linear regression modeling
5. Visualization and interpretation of the results

## Purpose

This project demonstrates the practical application of statistical modeling to financial data and reinforces concepts related to **regression analysis, data analysis, and machine learning**.
